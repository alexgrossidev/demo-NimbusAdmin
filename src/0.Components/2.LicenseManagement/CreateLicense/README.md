# Form structure

Step 1: Start license
Step 2: Ask email address
Step 3: Ask business info and request access data
Step 4: Is it trial?
Step 5: 
    Trial -> 
        Start date
        Trial length
        Should I create a license after the trial?
        YES ->
            License end date
        
    Paid ->
        Start date
        License end date

Step 6: Role of the license

Step 7: Should I send the license info straight away?

Step 8:
    YES ->
        Write a custom message (optional)

    NO ->
        Schedule date 
        Write a custom message (optional)

Step 9: Review and submit
